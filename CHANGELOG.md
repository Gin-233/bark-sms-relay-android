# Changelog

## 1.0.0

- First standalone Bark-only release.
- Added encrypted SMS queuing, Wi-Fi-bound Bark delivery, bounded retries, inbox reconciliation, and daily health heartbeats.
- Added a new independent application ID and Keystore alias so this public app cannot access data from private variants.
- Added bilingual documentation, privacy and security policies, repository templates, GitHub Actions builds, and public-tree leak checks.
