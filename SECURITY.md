# Security policy

## Supported versions

Security fixes target the latest `1.0.x` release. Development builds and older releases are not supported.

## Reporting

Use GitHub private vulnerability reporting when it is enabled for the repository. If it is unavailable, open a minimal issue asking the maintainers for a private contact method; do not include vulnerability details in that issue.

Include the affected version or commit, impact, and safe reproduction steps. Never include SMS content, phone numbers, Bark Device Keys, private signing keys, device identifiers, or unredacted logs and screenshots. Response and remediation timelines are not guaranteed. Maintainers may publish a coordinated advisory and credit reporters who request it.
